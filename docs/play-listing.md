# Google Play: what the store listing must say

Telegram's API Terms require two things of a third-party client's store listing:

- **2.2** — say prominently that the app uses the Telegram API and is part of
  the Telegram ecosystem;
- **3.2** — list every way the app makes money. Humogram makes none, and saying
  so is the honest way to meet it.

The app says the same on its first intro slide (`jac_intro_m1`) and on the
About screen (`jac_about_telegram_api`). Keep all three in step.

## Where it goes

Play Console → Humogram → **Grow users → Store presence → Main store listing**
→ **Full description**, for each language (uz is the default, then ru and en
under *Manage translations*). Put the block **at the top** of the full
description so it is visible without "Read more"; the rest of the description
stays as it is. Then *Save* and send the listing for review.

The short description (80 characters) need not carry it, and the app title must
not contain "Telegram" (2.3).

## The block

### O'zbekcha (uz)

```
Humogram — Telegram API asosida ishlab chiqilgan norasmiy ilova va Telegram ekotizimining bir qismi. U Telegram bilan bog'liq emas va Telegram tomonidan tasdiqlanmagan.

Ilova bepul: reklama, pullik funksiyalar, obunalar va xayriyalar yo'q.
```

### Русский (ru)

```
Humogram — неофициальное приложение на основе Telegram API, часть экосистемы Telegram. Оно не связано с Telegram и не одобрено Telegram.

Приложение бесплатное: без рекламы, платных функций, подписок и пожертвований.
```

### English (en)

```
Humogram is an unofficial app built on the Telegram API and part of the Telegram ecosystem. It is not affiliated with or endorsed by Telegram.

The app is free: no ads, no paid features, no subscriptions, no donations.
```

If the app ever starts earning (ads, a paid feature, donations), the second
paragraph must change to name it in every language before that release ships.
